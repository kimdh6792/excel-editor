# Excel Editor

엑셀 파일(`.xlsx`)과 CSV를 열어 **값과 서식을 고치고 원래 파일에 그대로 덮어쓰는** macOS 앱.

Numbers로 엑셀 파일을 열면 서식이 뭉개지고, 저장하면 파일이 변형된다. 그게 싫어서 만들었다.

> **macOS 전용입니다.** Windows·Linux는 빌드도 실행도 해 본 적이 없습니다.
> *macOS only. Documentation is in Korean.*

---

## 설치

배포되는 앱 파일이 없으므로 직접 빌드해야 한다. 처음이면 20분쯤 걸리고, 대부분은 기다리는 시간이다.

### 1. 필요한 도구 설치

터미널을 열고 아래를 차례로 실행한다. 이미 깔려 있으면 건너뛰어도 된다.

```bash
xcode-select --install                 # Xcode 명령줄 도구 (창이 뜨면 설치 눌러주세요)
brew install node pnpm                 # Node.js 와 pnpm
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh   # Rust
```

Homebrew(`brew`)가 없으면 [brew.sh](https://brew.sh) 에서 먼저 설치한다.
Rust 설치 후에는 터미널을 한 번 닫았다 열어야 인식된다.

### 2. 내려받아 빌드

```bash
git clone https://github.com/kimdh6792/excel-editor.git
cd excel-editor
pnpm install
pnpm tauri build
```

마지막 명령이 오래 걸린다(처음엔 5~10분). Rust 컴파일 로그가 쭉 올라가는 게 정상이다.

### 3. 응용 프로그램으로 옮기기

빌드가 끝나면 `src-tauri/target/release/bundle/macos/` 안에 **Excel Editor.app** 이 생긴다.
Finder로 열어 `/응용 프로그램` 으로 끌어다 놓는다.

```bash
open src-tauri/target/release/bundle/macos/
```

이제 Spotlight(`⌘Space`)에서 "Excel Editor"로 찾아 실행할 수 있다.

### 4. (선택) 엑셀 파일 기본 앱으로 지정

이걸 하면 `.xlsx` 파일을 더블클릭할 때 Numbers 대신 이 앱이 열린다.

1. 아무 `.xlsx` 파일을 Finder에서 우클릭 → **정보 가져오기** (`⌘I`)
2. **다음으로 열기** 항목에서 `Excel Editor` 선택
3. 바로 아래 **모두 변경…** 버튼 → 확인

되돌리고 싶으면 같은 자리에서 Numbers를 고르고 다시 "모두 변경"을 누르면 된다.

## 사용법

### 파일 열기

네 가지 방법이 있다.

- 툴바의 **열기** 버튼 (`⌘O`)
- 창에 파일을 **끌어다 놓기**
- Finder에서 **더블클릭** (위 4단계를 했을 경우)
- 툴바의 **최근** 메뉴 — 최근 연 파일 15개가 남고, 앱을 껐다 켜도 유지된다

### 편집

리본 메뉴로 글꼴·색·테두리·정렬·숫자 서식을 바꾼다. 수식 입력줄도 있다.
`데이터` 탭에 **필터**와 **정렬**이 있다.

### 저장

| 단축키 | 동작 |
|---|---|
| `⌘S` | 저장 (원래 파일에 덮어쓰기) |
| `⇧⌘S` | 다른 이름으로 저장 |
| `⌘O` | 열기 |
| `⌘N` | 새 파일 |
| `⌘P` | 인쇄 |
| `⌘F` | 찾기·바꾸기 |

제목 표시줄에 **•** 이 보이면 저장되지 않은 변경이 있다는 뜻이다.

### 인쇄

툴바의 **인쇄** 버튼(`⌘P`)을 누르면 먼저 작은 설정 창이 열린다.

| 설정 | 뜻 |
|---|---|
| 범위 | 현재 시트 / 선택한 영역 / 모든 시트 |
| 눈금선 인쇄 | 셀마다 옅은 선을 그린다 |
| 한 페이지 폭에 맞춤 | 열 너비 비율은 그대로 두고 전체 폭을 용지에 맞춘다 (기본 켜짐) |
| 맨 위 N행 반복 | 머리글 행을 페이지마다 다시 찍는다 |

**인쇄…** 를 누르면 macOS 기본 인쇄 대화상자가 뜬다. 용지·방향(가로/세로)·여백·부수와
**PDF로 저장** 은 거기서 고른다. PDF로 내보내려면 대화상자 왼쪽 아래 `PDF ▾` → `PDF로 저장` 이다.

> 인쇄되는 그림은 화면 캡처가 아니라 **표를 다시 그린 것**이다. 값·숫자 서식·글꼴·색·
> 배경·테두리·병합·정렬·줄바꿈·열 너비·행 높이는 그대로 가고, 숨긴 행과 열은 빠진다.
> 재현되지 않는 것은 아래 [알려진 제약](#알려진-제약)에 적어 뒀다.

### 백업

툴바의 **백업** 체크박스가 기본으로 켜져 있다. 켜져 있으면 저장할 때마다
덮어쓰기 **직전의 원본**을 같은 폴더에 `이름.bak.xlsx` 로 복사해 둔다.

직전 1회분만 보관한다. 두 번 저장하면 맨 처음 원본은 사라지므로, 중요한 파일은
작업 전에 따로 복사해 두는 편이 확실하다.

## ⚠️ 저장하기 전에 알아둘 것

**아래 기능은 저장하면 사라진다.**

차트 · 피벗 테이블 · 이미지와 도형 · 매크로(VBA) · 조건부 서식 · 데이터 유효성 ·
표(Table) 서식 · 메모 · 외부 링크 · 슬라이서

파일을 열 때 이런 게 들어 있으면 **노란 경고 배너**가 뜨고, 저장을 누르면 한 번 더 확인을 받는다.
조용히 날아가지는 않지만, 경고가 뜬 파일은 원본을 따로 백업해 두는 게 안전하다.

이유: 저장은 ExcelJS 라이브러리가 파일을 처음부터 다시 써내는 방식인데, 이 라이브러리가
다루지 못하는 요소는 다시 써낼 때 빠진다.

### 보존되는 것

값 · 수식과 계산 결과 · 날짜 · 숫자 서식 · 글꼴(이름, 크기, 굵게, 기울임, 밑줄, 취소선,
색, 위/아래 첨자) · 배경색 · 테두리(4방향 + 대각선, 13종 선 스타일) · 정렬(가로, 세로,
줄바꿈, 회전, 들여쓰기) · 병합셀 · 열 너비 · 행 높이 · 숨긴 행과 열 · 틀 고정 ·
눈금선 표시 · 시트 탭 색 · 시트 순서와 숨김 · 서식 있는 텍스트 · 하이퍼링크

건드리지 않은 행·열은 **반복해서 저장해도 크기가 밀리지 않는다.**

## CSV 다루기

`.csv` `.tsv` `.txt` 를 열고 저장한다.

- **한글 깨짐 처리** — 윈도우 엑셀이 저장한 CP949 파일과 UTF-8 파일을 자동으로 구분해 읽는다.
  저장은 항상 엑셀이 제대로 읽는 형식으로 한다.
- **구분자 자동 인식** — 쉼표·탭·세미콜론·파이프 중 알아서 고른다.
- **숫자로 바꾸지 않는다** — 전화번호(`01012345678`)나 우편번호(`06236`)처럼 앞자리가 0인 값,
  15자리가 넘는 긴 ID는 **텍스트 그대로** 둔다. 날짜처럼 생긴 문자열도 날짜로 바꾸지 않는다.
  다른 도구가 데이터를 망가뜨리는 지점이 정확히 여기라서, 일부러 보수적으로 만들었다.

2.4MB / 34,318행 파일 기준 0.1초 안에 열리고, 열었다 저장해도 **20만 개 셀이 전부 그대로**인 걸 확인했다.

## 알려진 제약

- 한 셀 안에서 글자마다 서식이 다른 텍스트는 **평범한 텍스트로 보인다.** 그 셀의 내용을
  건드리지 않으면 저장할 때 원래 서식이 복원되고, 고치면 평범한 텍스트가 된다.
- 수식 계산은 Univer 엔진이 한다. 엑셀의 모든 함수를 지원하지는 않는다. 저장한 파일에는
  "열 때 다시 계산" 표시를 넣어 두어서, 엑셀에서 열면 엑셀이 다시 계산한다.
- 필터를 걸어둔 파일은 **필터 범위는 유지되지만 어떤 값을 걸러뒀는지는 저장되지 않는다.**

### 인쇄

- **회전시킨 글자와 대각선 테두리는 평범하게 인쇄된다.** CSS 표에 대응하는 표현이 없다.
  셀 안에서 글자마다 서식이 다른 텍스트도 (화면과 마찬가지로) 평범한 텍스트로 나간다.
- 열보다 긴 값은 **옆 칸으로 넘치지 않고 잘린다.** 엑셀은 오른쪽 칸이 비어 있으면 넘겨서
  보여주는데, 인쇄물에는 넘칠 자리가 없다. 길면 열을 넓히거나 줄바꿈을 켜면 된다.
- **가로 인쇄를 앱에서 미리 지정할 수 없다.** macOS 인쇄 대화상자에서 고른다.
  (쓰는 라이브러리가 방향을 넘겨주지 못한다.)
- 페이지가 나뉘는 위치는 프린터가 정한다. 엑셀의 **페이지 나누기 미리보기 같은 기능은 없다.**
- 조건부 서식·차트·이미지는 애초에 열 때 사라지므로 인쇄에도 나오지 않는다.

## 개발

```bash
pnpm tauri dev     # 개발 모드로 실행 (코드 고치면 바로 반영)
pnpm dev           # 브라우저에서 화면만 (열기=업로드, 저장=다운로드)
pnpm test          # 테스트 209개
pnpm typecheck
pnpm tauri build   # .app / .dmg 만들기
```

| 영역 | 사용 |
|---|---|
| 앱 셸 | [Tauri 2](https://tauri.app) (Rust) — 네이티브 파일 다이얼로그, 8MB 바이너리 |
| 표 화면 | [Univer](https://github.com/dream-num/univer) (Apache-2.0) |
| xlsx 읽기/쓰기 | [ExcelJS](https://github.com/exceljs/exceljs) (MIT) |
| zip 검사 | [fflate](https://github.com/101arrowz/fflate) (MIT) |

Univer의 공식 xlsx 변환 기능은 별도 Docker 서버를 요구해서 쓰지 않고,
**ExcelJS ↔ Univer 변환기를 직접 구현**했다 (`src/xlsx/`, `src/csv/`).

구현하며 부딪힌 라이브러리 함정들, 파일 접근 권한 설계, 전체 파일 구조는
→ **[docs/구현-노트.md](docs/구현-노트.md)**
